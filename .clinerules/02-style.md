# Code & UI style
- TypeScript strict; small pure functions; no `any` in new public interfaces.
- UI palette lives in CSS variables at the top of `public/styles.css`. Stamp red (`--stamp`) is only for stamps, overdue items and emergencies.
- Plain-language copy, sentence case, active verbs ("Mark as filed", not "Submit").
- Accessibility: keyboard focus visible, labels on every input, `lang` attribute on non-English text.
