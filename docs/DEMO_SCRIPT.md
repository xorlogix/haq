# Demo video script (≈4 minutes)

**Setup:** Chrome, `npm start` running, `.env` with `CLINE_API_KEY` (live model). Set browser zoom to 90% and clear old cases (`data/` folder). Keep `HAQ_MODE=demo` ready as a fallback.

| Time | Screen | Say |
|---|---|---|
| 0:00–0:20 | Photo of a pothole / title card "हक़ Haq" | "There's a pothole outside Ramesh's house in Guwahati. A scooter rider fell last night. Ramesh doesn't know if it's GMC, PWD or NHAI, has never filed an RTI, and doesn't write formal English. Millions of Indians are stuck exactly here. That's why we built Haq." |
| 0:20–0:45 | Home screen → tap **Speak**, say in Hindi: *"GS Road pe Ganeshguri flyover ke paas bada gaddha hai, teen hafte se. Kal ek scooter wala gir gaya."* Add a photo → **Open my case** | "He just speaks, in Hindi, and adds a photo." |
| 0:45–1:25 | The live log on the left: authority → law → complaint → checklist → RTI → **red check: 'why' question** → rewrite → green | "This is a Cline SDK agent working the case like a repo. It finds the responsible office in our grounded directory, so it doesn't invent helplines, and pulls the relevant law. Then it drafts the complaint and the RTI. Watch this: the filing checklist catches a 'why' question, which PIOs reject. The agent rewrites it as a request for records and re-checks until it passes. Plan, act, verify, the same harness loop Cline uses on code." |
| 1:25–1:55 | DRAFTED stamp lands. "What to do" tab → **Read aloud** (Hindi TTS) → steps with GMC link | "Ramesh gets everything in Hindi, read aloud if he can't read well. The right office, the exact filing steps, and what evidence to keep." |
| 1:55–2:15 | RTI tab → highlighted blanks → **Fill in / edit** → Print / WhatsApp → tap **"Get a copy in Hindi"** → a translated explainer appears as a new tab | "The RTI itself is always in English — every office accepts it. But Ramesh can tap one button and get a faithful Hindi copy for himself, with the blanks kept exactly as-is, so he actually understands what he's about to file." |
| 2:15–2:35 | Back to the home screen → tap **"Explain a notice I received"** → attach a photo of a bank/court notice, no text needed → **Open my case** → log shows the agent reading the photo → an "Explainer" tab appears: who sent it, what it wants, the deadline, what happens if ignored | "Not every case starts with a complaint. Lots of people get a notice they can't make sense of — a bank letter, a court summons. Ramesh just photographs it. Haq reads it and explains, in Hindi, who sent it and what to do — and if the photo's too blurry to read, it says so honestly instead of guessing." |
| 2:35–2:55 | Deadlines tab → set filed date to 35 days ago → **Mark as filed** → red **No reply — draft my First Appeal** → agent drafts Sec. 19(1) appeal → APPEAL stamp → tap **"Print full case file"** → a complete printout with summary, steps and every document, one per page | "Haq doesn't stop at a chat. The deadlines come from the statute, not the model. When the department stays silent past 30 days, one tap and the same agent continues the case and writes the First Appeal — and the whole file prints as one clean document for his records." |
| 2:55–3:15 | VS Code: Cline panel building feature #1 from `docs/CLINE_BUILD_PROMPTS.md` (Plan → Act, running `npm test`) | "We built Haq with Cline as our coding partner. Here it's adding translated copies of drafts, and it runs our tests to check its own work. Our `.clinerules` keep it from inventing helplines, the same rule the product follows." |
| 3:15–3:55 | Haq running with no `.env` file at all — `/api/status` on screen shows `"credentialSource": "signed-in Cline account"` | "No API key, no config — Haq just reuses the Cline account already signed in on this machine. Judges, teammates, anyone can clone this repo and get live AI in one command." |
| 3:55–4:00 | Title: "Haq — every citizen's caseworker. Built with Cline." | "Haq. Your right, in your language." |

**Backup plan:** if the network drops, restart with `HAQ_MODE=demo npm start`. The agent loop, tools and checklist are the same, only the model is scripted. Say so honestly if asked.
